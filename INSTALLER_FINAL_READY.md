## 🆘 **TROUBLESHOOTING FOR USERS**

### Installation Issues
**"Installation seems to hang"**
- Normal - extracting 3.62 GB takes 15-20 minutes
- Do not force close - let it complete
- Check disk space (need 40GB free)

**"Windows Defender blocked it"**
- Normal for unsigned EXE
- Click "Run anyway"
- Consider code signing for production (~$200/year)

**"Can't find extraction progress"**
- Check C:\Users\<user>\AppData\Local\Temp for "adesso-install-*" folders
- One of these is the extraction in progress

### Runtime Issues
**"Can't access http://localhost:3000"**
- Wait 10 minutes on first launch
- Docker daemon starting for first time
- Run: `docker compose ps` from install directory
- Check firewall allows Docker

**"Services won't start"**
- Check 40GB disk space available
- Check 8GB RAM available
- Check Windows Event Viewer for errors
- Try running stop.bat then launch.bat again
