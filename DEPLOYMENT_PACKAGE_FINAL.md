## 🆘 USER SUPPORT

### Installation Troubleshooting

**"Installation failed"**
- Ensure 40GB free disk space
- Run as Administrator
- Try again or reinstall

**"Docker images folder not found"**
- Verify docker-images/ copied to installation folder
- Check: C:\Program Files\Adesso\DocumentAnalyzer\docker-images\
- Copy again if missing

**"Can't access http://localhost:3000"**
- Wait 10 minutes on first launch
- Check: `docker compose ps`
- Verify services running

### Runtime Issues

**"Services won't start"**
- Check Docker daemon running
- Check disk space
- Review logs: `docker compose logs`

**"Images won't load"**
- Ensure docker-images folder is present
- Check disk space
- Review: load-images.bat logs
